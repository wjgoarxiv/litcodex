# Code of conduct

Contributors and maintainers should make issues, reviews, discussions, and other
project spaces useful and respectful. Critique the work with concrete evidence,
accept corrections, and leave room for different backgrounds and experience.

Harassment, threats, discriminatory abuse, unwanted sexual attention, and sharing
someone's private information without consent are unacceptable. Do not use issue
threads to target individuals or repeatedly disrupt technical discussion.

Maintainers may edit or remove harmful content, lock a discussion, or restrict
participation when needed. Responses should consider the impact, severity, and
whether the behavior is repeated. Maintainers are held to the same expectations.

To flag a problem, ask a maintainer to review the relevant project thread. Share
only information safe for that audience. If sensitive details are necessary,
request a private contact route first; this repository does not declare a
dedicated confidential conduct-reporting channel. For software vulnerabilities,
follow [SECURITY.md](SECURITY.md).
