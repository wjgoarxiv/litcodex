# Conference planning mode

## Codex-native contract

Select plan in the picker. Planning is read-only; after approval hand work to native `start-work`
and `lit-loop`. Proposals remain `REVIEW_REQUIRED` and cannot programmatically claim family
completion. Changed evaluator or budget requires re-planning and review.

Define objective, metric/rubric, partition, positive researcher/round/iteration/noise budgets, finite
nonnegative min delta, host-bounded lane limits, source policy, paths, prohibited actions, synthesis
expectations, and evidence. Approved scaffolding uses
`<loaded-autoconference-skill-dir>/scripts/init_conference.py`; it does not start work.
