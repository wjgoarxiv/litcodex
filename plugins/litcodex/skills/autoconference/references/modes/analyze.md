# Conference analysis mode

## Codex-native contract

Select analyze in the picker; hand approved report writes to native `start-work` and `lit-loop`.
Analysis remains `REVIEW_REQUIRED` and cannot programmatically claim family completion. Changed
evaluator or budget requires re-planning and review.

Compare validated contributions, failed approaches, review reversals, knowledge-transfer value,
dissent, and uncertainty. Reject stale or child-authored shared artifacts. Return a claim/evidence
matrix, transferable insights, failure taxonomy, honest conference ROI, and missing evidence.
