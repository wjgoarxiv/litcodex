# Autoresearch core principles

Picker guidance hands approved work to native `start-work` and `lit-loop`; family artifacts remain
`REVIEW_REQUIRED` and cannot programmatically claim completion.

1. One primary metric; invariants are guards.
2. Stable mechanical evidence where promised; judgment stays labeled.
3. One attributable change per work iteration.
4. Keep only confirmed improvement; revert only owned edits.
5. Record failures, noise, blockers, and cleanup.
6. Stay inside the approved proposal and paths.
7. Continue only while the host workflow authorizes work.
8. Target evidence, `BUDGET_EXHAUSTED`, blocked, cancelled, and inconclusive remain review labels.

Changed evaluator or budget requires re-planning and review. Baseline is iteration zero; a work
budget of one still executes one candidate experiment.
