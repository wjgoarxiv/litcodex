# Debug investigation techniques

## Codex-native contract

The picker loads this catalog; approved probes run through native `start-work` and `lit-loop`.
Outputs are `REVIEW_REQUIRED` and cannot programmatically claim family completion. Changed evaluator
or budget requires re-planning and review.

Prefer deterministic reproduction, redacted boundary logging, input bisection, dependency isolation,
and invariant checks. Elevated tracing, credentials, network capture, host configuration, or
outside-root access requires separate approval. Record why each probe discriminates and its cleanup.
