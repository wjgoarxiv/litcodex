# Mechanical evaluator contract

## Codex-native contract

The picker loads this inert guidance; approved execution is handed to native `start-work` and
`lit-loop`. Evaluator artifacts are `REVIEW_REQUIRED` and cannot programmatically claim family
completion. Changed evaluator or budget requires re-planning and review.

Accept one bounded JSON object such as `{"pass":true,"score":0.94}`. Score is higher-is-better;
preserve the domain measurement separately. Reject NaN, infinity, schema drift, trailing output, and
an evaluator change. Use the host's bounded process contract and retain command identity, raw result,
guards, and cleanup as review evidence.
