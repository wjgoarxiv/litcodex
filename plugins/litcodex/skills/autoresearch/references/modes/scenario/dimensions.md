The picker loads this inert catalog; approved probes use native `start-work` and `lit-loop`.

or budget requires re-planning and review.

Consider actor, timing, scale, input validity, permissions, dependency health, network, filesystem
identity, concurrency, interruption, recovery, and evidence quality. Select dimensions that can
change the decision and state unexamined dimensions explicitly.
