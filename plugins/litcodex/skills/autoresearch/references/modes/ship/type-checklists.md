# Artifact-type shipping checklists

## Codex-native contract

The picker loads these checklists; approved checks use native `start-work` and `lit-loop`. Results
remain `REVIEW_REQUIRED` and cannot programmatically claim family completion. Changed evaluator or
budget requires re-planning and review.

Packages: reproducible build, exact payload, executable modes, runtime requirements, install smoke,
version lockstep, licenses, provenance, scanner, and dry packaging. Applications: tests,
accessibility, security, migrations, rollback, monitoring, and docs. Skills: picker registration,
installed paths, prompt boundaries, package enrollment, recursive scans, and host-shaped probes.
