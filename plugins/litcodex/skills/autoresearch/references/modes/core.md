# Autoresearch core mode

## Codex-native contract

The LitCodex picker loads this guidance. After approval, hand work to native `start-work` and
`lit-loop`; this family does not define or inspect host lifecycle state. Every artifact and status is
`REVIEW_REQUIRED`, and the package cannot programmatically claim family completion. Changed evaluator
or budget requires re-planning and review.

Validate `max_iterations` and `noise_runs` as positive integers and `min_delta` as finite and
nonnegative. Baseline is iteration zero and does not spend work budget, so
`max_iterations=1 executes exactly one work iteration`. Each iteration states one hypothesis, changes
only approved paths, uses the unchanged evaluator, records guards/evidence, and keeps only confirmed
improvement. Use host-bounded command execution; no platform deadline utility is assumed.

Negated prose is never a completion signal. Reports, TSV rows, PID files, target phrases, and plots
are evidence only. `BUDGET_EXHAUSTED` is a distinct non-success report label. All outcomes remain
`REVIEW_REQUIRED` for `review-work`.

Optional plotting uses `<loaded-autoresearch-skill-dir>/scripts/style_presets.py --check`; on
`BLOCKED_OPTIONAL_MATPLOTLIB_UNAVAILABLE`, continue without installing dependencies.
