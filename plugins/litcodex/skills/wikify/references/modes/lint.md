# Wiki lint mode

## Codex-native contract

Select lint in the picker; approved repairs use native `start-work` and `lit-loop`. Findings remain
`REVIEW_REQUIRED` and cannot programmatically claim family completion. Changed evaluator or budget
requires re-planning and review.

Check broken links/backlinks, orphan pages, duplicate ids, source drift, unresolved review states,
stale accepted claims, malformed frontmatter, root escapes, symlinks, and navigation mismatch. Report
deterministically before edits; never delete, merge, accept, or reorganize automatically.
